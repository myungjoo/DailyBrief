이 화면을 읽는 방법

신선도는 주기 기준으로 판정한다. daily는 1일 이내, weekly는 7일 이내, monthly는 31일 이내가 최신이다. 주기를 등록하지 않은 manual 항목은 오래된 것이 결함이 아니므로 판정하지 않고 경과 일수만 표시한다. 이번 회차는 세 에이전트 모두 2026-07-31에 갱신되어 전부 최신이다.

호출은 복사까지가 이 페이지의 역할이다. 발행된 페이지는 로컬 Claude Code 서브 에이전트를 실행할 수 없다. 커맨드 칩을 누르면 커맨드가 클립보드에 복사된다 - 복사해 Claude Code 터미널에 붙여넣으면 해당 에이전트가 실행된다.
