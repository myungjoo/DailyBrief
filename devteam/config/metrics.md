# 지표 정의와 해석 원칙

> `dev-activity-monitor` 가 매 실행 시 읽는다. 계산식을 바꾸면 과거 스냅샷과 비교가 깨지므로,
> 정의를 수정할 때는 `state/activity-history.json` 의 해당 시점 이후 스냅샷에 변경 사실을 남긴다.

## §1 수집 지표

| 지표 | GraphQL 필드 / 계산 | 단위 |
|---|---|---|
| 커밋 수 | `contributionsCollection.totalCommitContributions` | 건 |
| PR 생성 | `pullRequestContributions.nodes` 개수 | 건 |
| PR 머지 | 위 중 `state == MERGED` | 건 |
| 머지율 | PR 머지 / PR 생성 | % |
| 리뷰 제출 | `totalPullRequestReviewContributions` | 건 |
| 리뷰 범위 | `pullRequestReviewContributions` 의 서로 다른 `pullRequest.author.login` 수 | 명 |
| 이슈 기여 | `totalIssueContributions` | 건 |
| 활동일 수 | `contributionCalendar` 중 `contributionCount > 0` 인 날 | 일 |
| PR 규모 | `additions + deletions` 의 **중앙값** (합계 아님) | 줄 |
| 변경 파일 수 | `changedFiles` 의 중앙값 | 개 |
| 사이클 타임 | `mergedAt - createdAt` 의 **중앙값** | 시간 |
| 레포 집중도 | 상위 1개 레포 커밋 / 전체 커밋 | % |
| 주말 활동 비중 | 토·일 기여 / 전체 기여 | % |
| 비공개 기여 | `restrictedContributionsCount` | 건 (조회 불가분) |

**중앙값을 쓰는 이유**: 자동 생성 파일 1개, 대량 삭제 1건, lockfile 갱신 1건이 평균과 합계를
통째로 왜곡한다. 중앙값은 "이 사람의 전형적인 작업 단위"를 보여준다.

## §2 지표를 쓰지 않는 방식 (금지 목록)

아래는 이 파이프라인에서 **명시적으로 금지**한다. 흔히 쓰이지만 잘못된 측정이기 때문이다.

| 금지 | 이유 |
|---|---|
| 코드 줄 수(LOC)를 생산성으로 환산 | 1,000줄 삭제가 1,000줄 추가보다 가치 있는 경우가 흔하다. 리팩터링·설계·디버깅은 줄 수로 안 나타난다 |
| 커밋 수로 인원 순위 매기기 | 커밋 단위 습관(squash vs 잦은 커밋)이 사람마다 다르다. 습관을 성과로 오독한다 |
| 역할이 다른 인원을 같은 숫자로 비교 | Staff 엔지니어의 낮은 커밋 수는 정상이다. 리뷰·설계가 그 사람의 산출이다 |
| 단일 종합 점수 산출 | 다차원 활동을 1차원으로 압축하면 압축 과정의 가정이 결론을 결정한다 |
| 연속 활동일수(streak)를 미덕으로 | 번아웃을 장려한다. 주말 활동은 과부하 신호로만 쓴다 |
| 비공개 기여를 0으로 취급 | 관측 범위 밖이라는 뜻이지 활동이 없다는 뜻이 아니다 |
| 사이클 타임을 개인 속도로 해석 | 대부분 리뷰 대기·CI 지연이다. 프로세스 지표로 먼저 읽는다 |

## §3 해석 우선순위

1. **팀 지표 → 개인 지표.** 팀 총량이 움직였으면 개인 변동은 그 결과일 수 있다.
2. **설명 가능성 검토 → 신호 판정.** 휴가·릴리즈·조직 이벤트(`roster.md` §5)로 설명되면 그렇게 쓴다.
3. **정체(stalled) 우선.** 임원이 즉시 개입해 풀 수 있는 항목이 가장 실용적인 산출물이다.
4. **부분 관측 고지.** 비공개 기여·Enterprise 미포함·피처 브랜치 미집계를 매 회차 명시한다.

## §4 이 리포트의 용도 경계

- **용도**: 자원 배치 판단, 병목 발견, 과부하 확인, 기술 방향과 실제 코드 활동의 정렬 점검
- **비용도**: 인사 평가, 처우 결정, 개인 간 우열 판정

경계를 넘는 요청이 오면 지표의 한계를 먼저 설명한다. 부분 관측 데이터로 사람을 평가하면
측정되는 것만 늘어나고 측정되지 않는 일(리뷰, 멘토링, 설계, 장애 대응)이 사라진다.
