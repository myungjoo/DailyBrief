# AI 자본 흐름 브리핑 - 수동 실행

`ai-capital-monitor` 서브 에이전트를 즉시 호출해 투자 브리핑을 갱신한다.

## 실행

Agent 도구로 `subagent_type: "ai-capital-monitor"` 를 호출한다.
백그라운드로 두지 말고 `run_in_background: false` 로 실행해 결과를 바로 받는다.

프롬프트에 넘길 내용:

```
AI 자본 흐름 브리핑(투자·펀딩·M&A)을 생성해라.
- 에이전트 정의의 STEP 0~7을 순서대로 모두 수행할 것.
- capital/config/watchlist.md 를 먼저 읽고 감시 분야·전략적 투자자 명단·배점표를 확정할 것.
- capital/state/deal-ledger.json 의 딜 중복 제거 및 후속전개(UPDATE) 규칙을 반드시 적용할 것.
- System Software for NPU/LLM 축은 별도 검색을 반드시 돌릴 것(커버리지가 얇은 영역).
- 루머와 확정 딜을 절대 섞지 말 것.
- 리포트 파일과 Artifact 대시보드를 모두 갱신할 것.
{추가 지시사항}
```

## 인자 처리

사용자가 인자를 넘긴 경우 `{추가 지시사항}` 자리에 반영한다.

| 인자 예시 | 해석 |
|---|---|
| `--focus sys-software` / `시스템소프트웨어만` | 해당 분야에 가중해 수집. 다른 분야는 표만 유지 |
| `--focus npu` / `--focus llm` | 해당 기술 분야 집중 |
| `--company furiosa` / `퓨리오사` | 특정 기업 집중. 조달 이력 전체와 경쟁사 대비 구도를 확장 |
| `--investor samsung` / `삼성벤처` | 특정 투자자의 포트폴리오 움직임 집중 분석 |
| `--region kr` / `--region cn` / `한국` / `중국` | 특정 지역 집중. 현지어 소스 비중을 높인다 |
| `--min 100m` / `1억달러 이상` | 금액 기준선을 이번 회차만 조정 (기본 $50M) |
| `--since 1m` / `한 달` | 수집 창 확장 (기본 8일) |
| `--deep` / `자세히` | 상위 3개 딜을 1차 출처·공시까지 확인해 기술 상세와 투자자 명단을 확장 |
| `--ma` / `인수합병만` | M&A·인수만 수집. 라운드는 제외 |
| `--rumors` / `루머포함` | 루머·협상 단계 섹션을 확장해 상세히 (기본은 한 줄씩) |
| `--all` / `중복포함` | 딜 중복 제거를 이번 회차만 해제(전체 재확인용). `deal-ledger.json`은 정상 갱신 |
| `--ledger` / `원장만` | 신규 수집 없이 `deal-ledger.json` 기준 누적 리더보드·분야별 배분만 재집계 |
| 인자 없음 | 표준 주간 브리핑 |

## 완료 후

에이전트가 반환한 요약(한 줄 요약 · 핫 딜 3~5개 · System Software 축 결과 · 파일 경로 ·
Artifact URL · 집계)을 사용자에게 그대로 전달한다. 리포트 전문을 터미널에 다시 출력하지 않는다 -
파일과 웹 대시보드가 있다.

**금액을 요약에 옮길 때 확정/루머 구분을 유지한다.** 루머 금액을 확정처럼 전달하는 것이
이 파이프라인의 가장 큰 사고 위험이다.
